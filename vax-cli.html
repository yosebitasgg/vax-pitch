VAX CLI · 2026 01 / 08
— Capítulo I —

Por qué terminal.

La terminal convierte el motor en una herramienta directa: sin navegar pantallas, sin copiar datos entre sistemas.

Antes
UI primero

El usuario entra al SaaS, llena campos, guarda o revisa desde vistas específicas.

— bueno para operar visualmente.
Con CLI
1 comando

Cotiza, guarda, lista, registra feedback o diagnostica el backend desde el flujo de trabajo real.

— ideal para demo, scripts y automatización.
¹ El CLI no reemplaza la app: expone el mismo backend en una interfaz de bajo overhead. ² La autenticación y los perfiles locales permiten alternar entornos sin tocar código.
VAX CLI · 2026 02 / 08
— Capítulo II —

El mapa de comandos.

El binario principal se llama vax. Todo cuelga de siete superficies simples.

login Autentica el usuario. Browser login o fallback con email y contraseña.
quote Cotiza una carga. Wizard interactivo, flags, JSON o salida numérica.
quotes Opera el historial. Lista, detalle, feedback y cambios de estado.
whoami Confirma sesión. Usuario, rol, provider, backend y perfil activo.
doctor Diagnostica salud. Conectividad, token, permisos y auth contra backend.
config Guarda defaults. baseUrl y defaultProfile para trabajar local/prod.
VAX CLI · 2026 03 / 08
— Capítulo III —

Qué pasa por debajo.

El CLI no contiene el modelo: orquesta credenciales, arma requests y consume el backend de VAX.

Terminal vax quote, flags o wizard Ink.
→
@vax/client HTTP wrapper, token Bearer, errores tipados y perfiles.
→
Backend /quote, /quote/dual, /quotes, /distance.

Fig. 2. Arquitectura del cliente. La terminal es la puerta; la fuente de verdad sigue siendo el backend.

— Capítulo IV —

Auth, perfiles y diagnóstico.

Antes de cotizar, el CLI necesita saber a qué backend hablar y con qué usuario firmar la llamada.

setup 
$ vax config set baseUrl http://localhost:8001
$ vax login
abre /cli-login en navegador
$ vax whoami
$ vax doctor --json
Pieza Rol credentials.json token + expiración config.json baseUrl + perfil --profile local / prod / demo doctor prueba completa
¹ Los archivos viven en ~/.config/vax/; las credenciales deben tener permisos privados. ² VAX_API_URL y VAX_FRONTEND_URL permiten overrides por sesión.
VAX CLI · 2026 05 / 08
— Capítulo V —

Cotizar no es un endpoint; es un flujo.

El comando decide si pregunta datos, calcula distancia, pide predicción dual y guarda el resultado.

i. Entrada Wizard si no hay flags; modo script si recibe origen, destino, equipo y km.
ii. Ruta Busca ubicaciones conocidas, resuelve Places y calcula distancia si puede.
iii. Predicción /quote da venta; --dual trae venta, costo, utilidad y margen.
iv. Salida Ink visual, JSON puro, número con --quiet o guardado con status.
Campos relevantes: origen, destino, división, flujo, rango, equipo, pickup date, km, accesoriales, duración, peajes y altitud.
